# HowFar App Description

**HowFar** is a mobile application (Android/iOS) designed to help users quickly find the distance to the nearest essential public facilities and amenities in Toronto.

## Core Features
1. **Facility Distance List**: Displays a list of specific public facilities and the distance to the nearest one from the user's current location.
2. **Weather Integration**: Displays the current weather in downtown Toronto.
3. **Navigation Integration**: Tapping on any item in the list opens the Google Maps app with directions to that specific location.

## Supported Facilities
The app tracks the nearest of the following:
- Bike Share Toronto station (with at least one available bike)
- Bike Share Toronto station (with at least one available return dock)
- TTC Metro Station
- TTC Streetcar Station (North/South bound)
- TTC Streetcar Station (East/West bound)
- Public Library
- Park
- Tim Hortons branch
